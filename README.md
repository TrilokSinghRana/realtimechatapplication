# realtimechatapplication

A real-time chat application built using React, Node.js, Express, and Socket.IO. Users can join a chat room and send messages instantly without refreshing the page.

## Features

- Real-time messaging with Socket.IO
- Join chat with username
- Instant message updates
- Auto-scroll to latest messages
- Responsive UI
- User join and leave notifications

## Tech Stack

### Frontend
- React.js
- CSS
- Socket.IO Client
- React Scroll To Bottom

### Backend
- Node.js
- Express.js
- Socket.IO
